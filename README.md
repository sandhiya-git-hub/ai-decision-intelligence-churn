# AI Decision Intelligence System – Customer Churn

## 📌 Overview
This project is a cloud-deployed AI Decision Intelligence system designed to help businesses
identify customer churn risk, understand key drivers, and take data-driven retention actions.

Unlike traditional ML projects, this system goes beyond prediction by providing
explainability, prioritization, and actionable recommendations.

## 🎯 Key Features
- Customer churn risk prediction using machine learning
- Risk tiering: Critical, Moderate, Stable
- Explainable churn drivers
- Actionable primary and secondary recommendations
- Executive KPIs and visual analytics
- Prioritized decision panel for retention teams
- Downloadable executive decision report

## 🧠 Technology Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Streamlit
- Rule-based decision intelligence

## 🏢 Intended Users
- Customer Retention Teams
- Business Analysts
- Product Managers
- Strategy & Operations Teams

## 🚀 How to Use
1. Open the live application
2. Upload a customer dataset (CSV format)
3. Review executive KPIs and risk distribution
4. Focus on critical-risk customers
5. Take recommended retention actions

## 📂 Project Structure
app.py → Streamlit dashboard
decision_engine.py → Decision & recommendation logic
churn_model.pkl → Trained churn prediction model
features.pkl → Model feature list
requirements.txt → Dependencies
